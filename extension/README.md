# Extensión Lector GasteizLive

Extensión para Google Chrome y Microsoft Edge (Manifest V3) que abre la pestaña activa en el modo lector de GasteizLive (`/lector`).

## Instalación en Chrome / Edge

1. Abre el navegador y accede a la página de extensiones:
   - **Chrome**: `chrome://extensions`
   - **Edge**: `edge://extensions`
2. Activa el **Modo de desarrollador** (esquina superior o lateral).
3. Haz clic en **Cargar descomprimida** (o *Cargar extensión sin empaquetar*).
4. Selecciona esta carpeta (`extension`).
5. La extensión ya estará lista en la barra de herramientas. Al hacer clic sobre ella en cualquier noticia, abrirá el artículo en el lector.
